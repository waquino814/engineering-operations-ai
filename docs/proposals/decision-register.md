# Decision register

**Status: proposed. This register records; it decides nothing.** Statuses below are copied from the repository ([ADR index](../adr/README.md), [roadmap](../roadmap.md), [architecture](../architecture.md#open-decisions)) as of 2026-10-27. No ADR status was changed in preparing it. "Recommended" appears only where repository evidence supports a choice, and says which evidence.

Every option keeps the [absolute no-additional-spending policy](../roadmap.md#milestone-order): none involves a hosted request, a paid service, a credential or a model download, and **none asks for Ollama to be run or reconfigured by this repository**.
